# design/

Working files for the **Redesign v2** design canvas (see `../redesign_v2.md`).

- `Main.dc.html` — the proposed UI as a clickable prototype (412×915).
- `Before.dc.html` — the app as it stands at v1.15, for comparison.
- `DataModel.dc.html` — the data change behind the new screens.
- `canvas.json` — artboard layout.
- `solar-ev-roi-redesign.html` — the seeded, publishable canvas. Generated
  from the four files above; **edit those, never this one**, then re-seed.

Not part of the build. Vite only bundles `src/` and `public/`, so nothing here
ships to GitHub Pages.

**The numbers in these artboards are invented samples**, chosen to be
internally consistent for a Perth household. They are not the real dataset and
must not be treated as one. Per `CLAUDE.md`, real household data never enters
a tracked file.
